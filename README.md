# HALPTEC

Landing page estática e responsiva desenvolvida para a HALPTEC Serviços Elétricos, construída do zero com HTML, CSS e JavaScript puros — sem frameworks ou dependências externas.

## Sobre o projeto

Este projeto é inspirado em uma empresa real: a <a href="http://www.halptec.com.br/">HALPTEC</a>, empresa de serviços elétricos de São Bernardo do Campo/SP.

A página apresenta a missão e os valores da empresa, seu catálogo de produtos e serviços, e conta com um formulário de contato — apenas ilustrativo, já que o site é estático e não possui back-end.

## Funcionalidades

- Design responsivo, adaptado para desktop, tablet e mobile
- Navegação por seções com efeitos de scroll e parallax
- Acordeões para organizar conteúdo de forma compacta
- Pré-carregador (preloader) e transições animadas
- Formulário de contato (front-end apenas)

## Tecnologias

- HTML5
- CSS3, com estilos organizados por seção/componente
- JavaScript (vanilla), com módulos separados por responsabilidade
